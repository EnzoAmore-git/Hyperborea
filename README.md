# Hyperborea

Цифровой артбук и вебтун-комикс в мире славянского фэнтези для взрослой аудитории.

В работе я объединял иллюстрации, историю и атмосферное звуковое сопровождение. Развивал удобное чтение на телефоне, навигацию и визуальный ритм страниц, проверял доступность и скорость загрузки.
