# Саундтрек читалки

В читалке уже работает адаптивная музыка: она выбирает настроение по главе и
странице, плавно переходит между сценами и меняет плотность/интенсивность.
Звук по умолчанию выключен — включается кнопкой `♪` в верхней панели.

Сейчас используется встроенная процедурная тема на Web Audio API. Это не
нейросетевая музыка, а рабочий «черновик» без аудиофайлов: он нужен, чтобы
проверить переходы, громкость и UX. Когда будут готовы сгенерированные треки,
их можно подключить без изменения кода — через манифест.

## Что где лежит

- `src/data/soundtrack.js` — карта сцен: глава → диапазон страниц → настроение
  и интенсивность.
- `src/audio/SoundtrackEngine.js` — движок: процедурная тема, плавные переходы,
  загрузка файлов, громкость, пауза при скрытой вкладке.
- `src/hooks/useAdaptiveSoundtrack.js` — React-хук и хранение громкости.
- `public/audio/soundtrack/manifest.json` — список готовых треков. Пока пустой.
- `docs/soundtrack.md` — этот файл.

## Как включить

1. Открой читалку: `/read/6/1`.
2. Нажми `♪ Включить` в верхней панели.
3. Рядом появится регулятор громкости.
4. Музыка меняется при переходе между сценами: бой становится плотнее, дом —
   спокойнее.

Громкость запоминается в `localStorage` под ключом
`hyperborea:sound-volume`. Сам факт включения не запоминается: браузеры
запрещают автозапуск, поэтому каждый новый заход в читалку звук стартует
выключенным.

## Как заменить процедурную тему на нейромузыку

Нужны семь музыкальных состояний:

| mood | Сцена | Характер |
|---|---|---|
| `calm` | дом, госпиталь, разговоры | тёплый пад, редкие инструменты, без ударных |
| `mystery` | тайна, подземелье, поиск | низкий дрон, пространство, редкие сигналы |
| `tension` | тревога, подготовка, погоня | пульс, нарастающая перкуссия, напряжение |
| `battle` | бой, штурм | ударные, низкие струнные, хор, акценты |
| `sorrow` | похороны, потери | виолончель, мягкий пад, редкие колокола |
| `horror` | одержимые, тьма | диссонанс, дыхание, металлические удары |
| `sacred` | свет, храм, надежда | тёплый хор, колокола, мажорный пад |

Все состояния должны быть в одной тональной семье. Удобно взять ля минор
(A) и темпы 55–120 BPM: спокойные сцены медленнее, бой быстрее. Тогда
переходы не будут звучать как переключение радиостанций.

### 1. Сгенерировать треки

Подойдут Suno, Udio, Stable Audio, MusicGen, AIVA, Soundraw, Mubert или
другой сервис с коммерческой лицензией. Генерируй по 3–5 вариантов на каждое
состояние и выбирай лучший.

Примеры промптов (можно отправлять как есть):

- `calm`: `dark Nordic ambient, warm low strings, soft felt piano, distant wind, 55 BPM, A minor, no vocals, seamless loop, restrained cinematic atmosphere`
- `mystery`: `cold dark ambient, low drone, distant bowed metal, sparse heartbeat, 60 BPM, A minor, no vocals, seamless loop, mysterious`
- `tension`: `dark cinematic tension, pulsing low strings, heartbeat percussion, rising drone, 90 BPM, A minor, no vocals, seamless loop, suspense`
- `battle`: `epic dark battle score, low string ostinato, taiko drums, distorted brass, choir hits, 120 BPM, A minor, no vocals, seamless loop, aggressive`
- `sorrow`: `melancholic Nordic lament, solo cello, low drone, soft bells, 55 BPM, A minor, no vocals, seamless loop, grief`
- `horror`: `avant-garde horror ambient, dissonant string cluster, breathing noise, irregular metallic hits, 70 BPM, G, no vocals, seamless loop, unsettling`
- `sacred`: `sacred Nordic ambient, warm choir pads, bells, harmonic strings, 60 BPM, A major, no vocals, seamless loop, hopeful`

Если сервис умеет отдавать стемы — используй стемы. Иначе начни с одного
готового микса на состояние; этого достаточно для первого запуска.

### 2. Подготовить файлы

Требования:

- длительность 60–120 секунд;
- бесшовный луп: начало и конец совпадают по фазе, без тишины и щелчка;
- без вокала и без текста;
- одинаковый инструментальный характер внутри одной сцены;
- громкость примерно `-18 LUFS`, пик не выше `-2 dBTP`;
- формат: OGG/Opus (лучше для веса) или MP3 160–192 kbps (совместимее).

Пример конвертации через ffmpeg:

```bash
ffmpeg -i calm.wav -af loudnorm=I=-18:TP=-2:LRA=7 -c:a libopus -b:a 96k calm.ogg
```

Положи файлы в:

```text
public/audio/soundtrack/
  calm.ogg
  mystery.ogg
  tension.ogg
  battle.ogg
  sorrow.ogg
  horror.ogg
  sacred.ogg
```

Если делаешь стемы (например, отдельно база, ритм, хор), положи их рядом:

```text
public/audio/soundtrack/
  battle-base.ogg
  battle-drums.ogg
  battle-choir.ogg
```

### 3. Заполнить манифест

Открой `public/audio/soundtrack/manifest.json` и опиши все семь состояний.
Пока манифест пустой или в нём нет хотя бы одного состояния, движок играет
процедурную тему.

Пример с целыми миксами:

```json
{
  "version": 1,
  "states": {
    "calm": {
      "layers": [{ "src": "audio/soundtrack/calm.ogg", "gain": 1 }]
    },
    "mystery": {
      "layers": [{ "src": "audio/soundtrack/mystery.ogg", "gain": 1 }]
    },
    "tension": {
      "layers": [{ "src": "audio/soundtrack/tension.ogg", "gain": 1 }]
    },
    "battle": {
      "layers": [{ "src": "audio/soundtrack/battle.ogg", "gain": 1 }]
    },
    "sorrow": {
      "layers": [{ "src": "audio/soundtrack/sorrow.ogg", "gain": 1 }]
    },
    "horror": {
      "layers": [{ "src": "audio/soundtrack/horror.ogg", "gain": 1 }]
    },
    "sacred": {
      "layers": [{ "src": "audio/soundtrack/sacred.ogg", "gain": 1 }]
    }
  }
}
```

Пример со стемами и порогами интенсивности:

```json
{
  "version": 1,
  "states": {
    "battle": {
      "layers": [
        { "src": "audio/soundtrack/battle-base.ogg", "gain": 1, "from": 0, "to": 1 },
        { "src": "audio/soundtrack/battle-drums.ogg", "gain": 0.9, "from": 0.35, "to": 1 },
        { "src": "audio/soundtrack/battle-choir.ogg", "gain": 0.8, "from": 0.7, "to": 1 }
      ]
    }
  }
}
```

`from`/`to` — порог интенсивности сцены (0…1). Если сцена имеет
интенсивность 0.5, слой с `from: 0.7` будет тише/выключен, а слой с
`from: 0.35` уже включится. Это позволяет делать бой «нарастающим», не
переключая трек.

Это фрагмент: в рабочем манифесте должны быть все семь состояний, иначе
движок оставит процедурную тему.

Пути можно писать относительно корня сайта (`audio/soundtrack/...`) — движок
сам подставит `BASE_URL`, поэтому GitHub Pages и основной домен будут работать.

### 4. Проверить

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Открой `http://127.0.0.1:5173/read/6/1`, включи звук и проверь:

- в Network загружается `manifest.json` и треки;
- в консоли нет `assets unavailable`;
- при переходе 6/2 → 6/10 музыка становится тревожнее/боевой;
- при переходе 7/2 → 7/6 уходит в спокойствие;
- громкость регулируется, кнопка выключает звук;
- при уходе на другую вкладку звук останавливается.

В dev-режиме можно посмотреть состояние движка:

```js
window.__hbSoundtrackDebug()
```

Там будут `mode`, `cue`, `context`, `level`, `assetCache` и т.п.

Если файл не загрузился или не декодировался, движок пишет предупреждение в
консоль и автоматически возвращается к процедурной теме. Читатель не остаётся
в тишине.

## Как менять сцены

Все диапазоны — в `src/data/soundtrack.js`, в объекте `SCENES`. Номера страниц
соответствуют читалке (включая титульную страницу главы).

Например:

```js
'2': [
  { from: 1, to: 4, mood: 'tension', intensity: 0.45, label: 'Мёртвый дом' },
  { from: 5, to: 14, mood: 'battle', intensity: 0.85, label: 'Штурм' },
  { from: 15, to: 18, mood: 'battle', intensity: 0.7, label: 'Засада' },
]
```

Если добавляешь новую главу, добавь её в `SCENES` и `CHAPTER_DEFAULTS`. Если
главы нет в карте, сработает `FALLBACK_CUE` (`mystery`, 0.35).

Интенсивность влияет на:

- громкость слоёв в процедурной теме;
- фильтр (яркость);
- частоту пульса/бой;
- громкость слоёв в файловом режиме через `from`/`to`.

## Важные ограничения

- **Не запускай нейрогенерацию в браузере на каждый абзац.** Это тяжёлые
  модели, задержка, расход батареи и непредсказуемый результат. Генерируй
  музыку заранее, а в рантайме только смешивай готовые слои.
- **Не переключай музыку на каждом абзаце.** Сцена должна длиться хотя бы
  20–30 секунд; исключение — резкий сюжетный поворот.
- **Не делай музыку громкой по умолчанию.** Это фон для чтения, а не концерт.
- **Проверь лицензию.** Для Suno/Udio и других сервисов смотри условия
  коммерческого использования и права на распространение. Не используй имена
  живых музыкантов в промптах.
- **Не добавляй вокал с текстом.** Он будет конкурировать с книгой.
- **Следи за весом.** Семь минутных стерео-лупов в Opus — это несколько
  мегабайт; перед загрузкой на мобильных лучше предзагружать только текущую
  сцену (сейчас движок так и делает: грузит состояние по требованию).

## Что уже покрыто кодом

- выбор сцены по главе и странице;
- плавный кроссфейд между состояниями;
- слои и пороги интенсивности для файлового режима;
- встроенная процедурная тема как fallback;
- кнопка включения, громкость и сохранение громкости;
- остановка при уходе со вкладки;
- отключение при выходе из читалки;
- отсутствие автозапуска.

Осталось только сгенерировать и положить аудиофайлы, заполнить манифест и
