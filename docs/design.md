# Webtoon Reader — Дизайн

> Второй документ методологии OpenSpec. Детальный дизайн интерфейса: цвет, типографика, компоненты, анимации, layout, брейкпоинты.

## Общая концепция
Славянское фэнтези, тёмная эстетика, мистическая атмосфера. Главный принцип — иммерсивность: пользователь "проваливается" в мир. Вау-эффект создаётся через контраст света и тьмы, макро-типографику, кинематографичные переходы и сглаженный скролл. Абсолютный приоритет мобильных устройств.

## Цветовая палитра

### CSS Variables (темная тема — единственная)
```css
--bg-void:        #0b0a10;   /* глубинный фон страницы */
--bg-deep:        #12101a;   /* фоны карточек, секций */
--bg-raised:      #1b1826;   /* карточки, панели поверх фона */
--surface:        #221d30;   /* ховеры, инпуты, кнопки */
--line-subtle:    #2c2640;   /* тонкие разделители, рамки */
--text-primary:   #ece4d8;   /* основной текст — тёплый слоновый */
--text-secondary: #9a8f80;   /* вторичный текст, подписи */
--text-muted:     #6b6154;   /* приглушённый, для метаданных */
--accent-ember:   #c4491c;   /* основной акцент — ржавый/угольный огонь */
--accent-gold:    #d8a23a;   /* вторичный акцент — янтарь */
--accent-blood:   #8c1f28;   /* терция — кровь (использовать дозированно) */
--accent-ice:     #7fa8b8;   /* холодный мистический свет (магия, лёд) */
```

### Принципы использования
- **90/10 правило**: фоны занимают ~90%, акценты ~10%
- Акцентные цвета никогда не заливают большие области — только градиенты, линии, свечения, подчёркивания
- `--accent-ember` — главный призыв (кнопки поддержки, активные состояния)
- `--accent-gold` — премиальные элементы (звёзды, рамки глав)
- `--accent-ice` — магия/сверхъестественное в контексте контента
- Поверх видео и артов обязательны тёмные градиентные подложки для читаемости

## Типографика

### Подключение шрифтов
- Кастомные шрифты подключаются через `@font-face` локально — без внешних CDN (приватность, офлайн-доступ)
- Файлы хранятся в `public/fonts/`, все варианты — подмножества (latin, cyrillic) отдельными файлами

| Роль | Шрифт | Файлы | Путь |
|---|---|---|---|
| Дисплей/Заголовки | **Cormorant Garamond** | `CormorantGaramond-Regular.woff2`, `CormorantGaramond-Bold.woff2` | `public/fonts/CormorantGaramond/` |
| Основной текст | **Inter** | `Inter-Regular.woff2`, `Inter-Medium.woff2`, `Inter-SemiBold.woff2` | `public/fonts/Inter/` |
| Акценты/Код | **JetBrains Mono** | `JetBrainsMono-Regular.woff2` | `public/fonts/JetBrainsMono/` |

```css
@font-face {
  font-family: 'Cormorant Garamond';
  src: url('/fonts/CormorantGaramond/CormorantGaramond-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap; /* текст виден мгновенно, шрифт подставится потом */
}

@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter/Inter-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
```

### Font-display стратегия
- **Заголовки (Cormorant)**: `font-display: swap` — текст отрисовывается fallback-ом сразу, затем плавно подменяется (для hero-заголовков допустимо `optional` чтобы избежать FOUT)
- **Основной текст (Inter)**: `font-display: swap` — приоритет читаемости, никакого экрана без текста
- **Mono (JetBrains)**: `font-display: fallback` — используется редко, допустима короткая задержка отрисовки

### Визуальная иерархия типографики
```
─────────────────────────────────────────────────────
  01 / ГЛАВА

  ПРОЛОГ
─────────────────────────────────────────────────────
  Cormorant Garamond Bold, --fs-h1, --accent-gold underline
  ───────────────────────

  В мире, где тьма пожирает рассвет, древние башни стояли
  как кости мёртвого бога. Каждый камень хранил шёпот
  забытых эпох, а ветер нёс с собой запах дыма и железа.

  Inter Regular, --fs-body, --text-primary
─────────────────────────────────────────────────────
  Рис. 1 — Вид на руины башни Аргана
  JetBrains Mono, --fs-caption, --text-muted, uppercase
─────────────────────────────────────────────────────
```
- **Заголовок**: Cormorant, крупный, `letter-spacing: 0.12em`, underline `--accent-gold`
- **Основной текст**: Inter 400, 1rem, `line-height: 1.6`, `--text-primary`
- **Вторичный текст**: Inter 400, 0.875rem, `--text-secondary`
- **Мета/подписи**: JetBrains Mono или Inter, 0.6875rem, uppercase, `--text-muted`, `letter-spacing: 0.08em`

### Шкала типов — Fluid Type (clamp)
```css
--fs-display: clamp(2.5rem, 8vw, 5.5rem);  /* hero-заголовки */
--fs-h1:      clamp(2rem, 5vw, 3.5rem);    /* заголовки секций */
--fs-h2:      clamp(1.5rem, 3.5vw, 2.25rem);
--fs-h3:      clamp(1.25rem, 2.5vw, 1.75rem);
--fs-body:    1rem;   /* основной текст 16px */
--fs-small:   0.875rem;
--fs-tiny:    0.75rem;
--fs-caption: 0.6875rem;  /* капшены, uppercase с трекингом */
```

### Семейства
- **Дисплей/Заголовки**: серифный с характером — руны, зарубки, готический уклон
- **Текст**: читаемый нейтральный санс-сериф (антиквенный/гротеск)
- Заголовки секций — uppercase + `letter-spacing: 0.12em`, подчёркнуты янтарной линией
- Номера разделов («01 / Глава») — `--accent-gold`, `--fs-caption`

## Layout правила

### Сетка
- **Мобильная**: 4 колонки, gutter 16px, контентная ширина до 100%
- **Планшет**: 8 колонок, gutter 24px, контентная ширина 100%
- **Десктоп**: 12 колонок, gutter 32px, контентная ширина 1280px, но секции могут выходить на края (full-bleed)

### Общие правила
- Mobile-first: медиазапросы только на увеличение (`min-width:`)
- Контент центрируется, hero-секции и читалка — full-bleed
- Отступы секций: `clamp(4rem, 10vw, 8rem)` сверху/снизу
- Расстояния между блоками кратны 8px
- Всё, что можно, анимируется через `transform`/`opacity`, чтобы не вызывать reflow

### Split-screen 20/80 (галерея концептов)
- **Десктоп (≥1024px)**: фиксированная левая колонка (20%, sticky) с фильтрами по персонажам; правая зона (80%) — сетка артов
- **Планшет (≥768px)**: промежуточное состояние — левая колонка расширяется до 30%, правая — 70%. Фильтры остаются вертикальными, но с уменьшенным размером шрифта (`--fs-small`). При переходе от 30/70 к 20/80 анимация через CSS transition: `grid-template-columns 0.3s var(--ease-smooth)`
- **Мобильный (<768px)**: фильтры превращаются в горизонтальную полосу чипов под заголовком, сетка артов — 2 колонки
- Переход между брейкпоинтами: `@media (min-width: 1024px)` — триггер на финальное 20/80
- Левая колонка — минимализм: список персонажей вертикально, активный пункт подсвечен `--accent-ember` с маркером
- Переключение фильтра анимируется: смена сетки через Framer Motion `AnimatePresence` + GSAP-переход

## Компоненты UI

### 1. Navbar
- Стеклянная подложка (`backdrop-filter: blur(12px)`, тёмный градиент на edges)
- Слева — логотип/руна; справа — навигация (О проекте, Концепты, Команда, Поддержать)
- На мобильных — иконка-бургер, полноэкранное выезжающее меню
- Исчезает при скролле вниз, появляется при скролле вверх (GSAP ScrollTrigger)

### 2. Hero секция
- Фон: `sources/bg_video.mp4` (loop, muted, autoplay, playsinline) + тёмный градиент-оверлей
- Крупный заголовок, призыв «Читать комикс» (запускает полноэкранный режим читалки)
- Кнопка «О проекте» — плавный скролл вниз (Lenis)
- Первые секунды: лёгкий parallax заголовка, затемнение видео

### 3. О проекте
- Классический сплит: текст + изображение из `sources/ART`
- Изображение с hover-эффектом zoom + тень/виньетка
- Возможность параллакс-наклона при скролле

### 4. Галерея концептов
- 20/80 split-screen (см. Layout)
- Карточка арта: изображение, подпись персонажа, hover — приподнимание + янтарное свечение рамки
- Клик — полноэкранный lightbox с масштабированием

### 5. Команда
- Сетка карточек участников (фото/аватар в руне-рамке, имя, роль)
- Ховер: подсветка `--accent-ice`

### 6. Поддержать проект
- Три акцентные карточки: Boosty, Patreon, Соцсети
- Выделяются `--accent-ember`/`--accent-gold` рамками и свечением, увеличение при hover
- Иконки-ссылки, внешние ссылки с `rel="noopener noreferrer"`

### 7. Читалка комикса
- Полноэкранный режим с затемнением
- Слева/справа — огромные невидимые зоны клика «вперёд/назад» (на мобильных — края экрана)
- Снизу/сверху — панель глав и прогресс-бар чтения (position: sticky)
- Переключение страницы: GSAP-переход (справа-налево снять / слева-направо положить), лёгкий blur между страницами
- Escape/кнопка — выход из режима читалки
- Стрелки клавиатуры: ← →, PageUp/PageDown

#### Состояния загрузки
- **Первичная загрузка главы**: полноэкранный skeleton — контур страницы с пульсирующей заливкой (`--bg-raised` → `--surface`, shimmer через `--accent-ember-10`), прогресс «Загрузка главы…» внизу
- **Переход на следующую страницу**: страница держится на экране с лёгким blur, пока следующее изображение не догрузится (избегаем «мигания»)
- **Skeleton-пагинация**: при swipe вперёд показывается скелет следующей страницы (прозрачный контур + shimmer) до завершения `onload`
- Отмена отображения skeleton по событию `img.onload` ИЛИ по таймауту 2.5с (переход в fallback)

#### Ошибка загрузки изображения
- `onerror` → показ placeholder: тёмная карточка с иконкой-обрывом, текстом «Страница не загрузилась» и кнопкой «Повторить»
- Placeholder не ломает пагинацию: можно листать дальше, страница ставится в очередь на повторную попытку
- Ошибка сети целиком (глава не загрузилась) — полноэкранное сообщение с кнопкой «Попробовать снова» и ссылкой «Вернуться к оглавлению»
- Повторная попытка с экспоненциальным backoff: 1с → 3с → 9с, максимум 3 попытки на страницу

#### Preloading следующей страницы
- При просмотре страницы N асинхронно (приоритет ниже текущей) грузятся страницы N+1 и N+2
- Медиазапрос `prefers-reduced-data` (или `navigator.connection.saveData`) → preload отключается, грузится только текущая страница
- Используется `rel="preload"` + `<link>` или fetch с приоритетом `idle`

### 8. Footer
- Минимальный: лого, копирайт, ссылки, дисклеймер 18+

## Анимации и переходы

### GSAP
- **Intro/reveal**: секции появляются при входе в viewport (ScrollTrigger, `y: 60 → 0`, `opacity: 0 → 1`, задержка через stagger)
- **Параллакс**: изображения и фон hero движутся медленнее скролла
- **Hero-video**: лёгкий scale 1 → 1.08 при скролле
- **Navbar**: show/hide при направлении скролла

### Framer Motion
- **Появление секций**: `whileInView` с разовой анимацией
- **Фильтр галереи**: `AnimatePresence`, layout-переходы карточек
- **Lightbox**: scale/fade-in
- **Мобильное меню**: slide-in панель

### Lenis
- Глобальный сглаженный скролл на всех страницах
- Синхронизация с ScrollTrigger: `lenis.on('scroll', ScrollTrigger.update)`

### Спецэффекты (вау-элементы)
- **Текстура**: тонкая CSS-реалистичная зернистость/vignette-оверлей поверх фона (самопальный noise через SVG data-URI)
- **Свечение**: box-shadow с `--accent-gold`/`--accent-ember` при hover ключевых элементов
- **Live-линии**: тонкие линии-разделители, плавно растут по ширине при reveal
- **Редукция**: `@media (prefers-reduced-motion: reduce)` — отключает все анимации, скролл становится обычным
- **Мобильная производительность**: анимации только transform/opacity, ленивая загрузка изображений (`loading="lazy"`)

## Timing

### CSS Variables — длительности
```css
--dur-fast:   120ms;   /* hover, focus, микро-состояния кнопок */
--dur-medium: 320ms;   /* панели, тултипы, модалки, смена фильтров */
--dur-slow:   600ms;   /* секции, hero-reveal, lightbox scale/fade */
--dur-extra:  900ms;   /* intro-анимации, кинематографичные переходы читалки */
```

### Easing-кривые
```css
--ease-smooth: cubic-bezier(0.22, 1, 0.36, 1);  /* плавный выезд, без рывков */
--ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1); /* упругий отскок — карточки, свечения */
--ease-standard: cubic-bezier(0.25, 0.8, 0.25, 1); /* универсальная, для opacity/transform */
--ease-enter:  cubic-bezier(0.11, 0, 0.5, 0);   /* быстрый вход, медленный выход */
```
- **Fast** → hover-, active-состояния кнопок, инпутов: `--dur-fast` + `--ease-standard`
- **Medium** → модалки, мобильное меню, смена фильтров: `--dur-medium` + `--ease-smooth`
- **Slow** → reveal-секций, hero, page-transitions: `--dur-slow` / `--dur-extra` + `--ease-smooth`/`--ease-bounce`
- Триггер на эластичность: `--ease-bounce` только для декоративных элементов (карточки, свечения), никогда — для контента
- Все длительности передаются в GSAP/Framer Motion через константы, синхронизированные с CSS-переменными

| Название | Ширина | Поведение |
|---|---|---|
| Mobile S | ≥320px | базовая сетка 4 колонки, фильтры — чипы |
| Mobile L | ≥480px | сетка артов 2 колонки |
| Tablet | ≥768px | сетка 8 колонок, арты 3 колонки |
| Laptop | ≥1024px | сетка 12 колонок, split-screen 20/80 |
| Desktop | ≥1280px | контент 1280px, max-width |

- Стили для больших экранов объединяются в `@media (min-width: ...)`

## Доступность
- Контраст текста: минимум 4.5:1 для body-текста
- Фокус-состояния: заметное кольцо `--accent-gold` для клавиатуры
- Alt-тексты у всех изображений, aria-атрибуты у читалки
- Поддержка `prefers-reduced-motion`

### Keyboard navigation — читалка
| Клавиша | Действие |
|---|---|
| `←` / `PageUp` | Предыдущая страница |
| `→` / `PageDown` / `Space` | Следующая страница |
| `Home` | Первая страница главы |
| `End` | Последняя страница главы |
| `g` | Открыть навигацию по главам |
| `Escape` | Выйти из полноэкранного режима / закрыть панель |
| `m` | Переключить звук видео в hero |

- Читалка получает фокус при входе, `tabindex="0"` на контейнере
- Видимая подсказка о клавишах на первых секундах работы (с autohide)

### Focus trap — модалки и lightbox
- При открытии модалки/lightbox фокус переводится внутрь контейнера
- Tab/Shift+Tab циклически ходят только по фокус-элементам модалки (focus trap)
- На `Escape` — закрытие и возврат фокуса на элемент, открывший модалку
- Фоновая страница получает `inert`/`aria-hidden` пока модалка открыта

### Aria-labels для кнопок без текста
- Иконки-ссылки (бургер, закрытие, стрелки пагинации) — обязательный `aria-label`
- Примеры: `aria-label="Открыть меню"`, `aria-label="Назад"`, `aria-label="Вперёд"`, `aria-label="Закрыть (Esc)"`
- У кнопки «Читать комикс» — `aria-label="Читать комикс"` + текстовый контент
- Прогресс-бар чтения — `role="progressbar"` с `aria-valuenow`/`aria-valuemin`/`aria-valuemax`
- Панель глав — `role="dialog"` + `aria-modal="true"`

## Performance Budget

### Лимиты
| Метрика | Лимит | Примечание |
|---|---|---|
| Первый экран (LCP) | ≤ 2.5с | mobile, 4G |
| Первый контент (FCP) | ≤ 1.8с | mobile |
| Общий вес страницы | ≤ 1.5MB | без страниц читалки |
| **Видео hero** | ≤ 3MB | `bg_video.mp4`, 720p, muted, без звуковой дорожки |
| **Одна страница комикса** | ≤ 800KB | WebP, макс. ширина 1600px |
| CSS | ≤ 60KB | gzip, critical CSS в `<head>` |
| JS | ≤ 120KB gzip | весь бандл, читалка — отдельным чанком |
| Шрифты | ≤ 200KB суммарно | woff2, subset latin+cyrillic |

### Стратегии
- **Lazy loading**: все изображения и видео вне первого экрана — `loading="lazy"` + `decoding="async"`; контент первого экрана — `fetchpriority="high"`
- **Code splitting для читалки**: режим читалки — отдельный чанк (`import()` динамически), бандлится и грузится только при открытии
- **Critical CSS**: инлайн критический CSS для первого экрана (выше `--line-subtle`), остальное — асинхронно
- **Preload шрифтов**: `<link rel="preload" as="font" type="font/woff2">` для Cormorant Bold (заголовки первого экрана), Inter Regular — по мере необходимости
- Видео hero — `preload="none"` + poster, автозапуск только при видимости и `prefers-reduced-motion: no-preference`
- При `navigator.connection.saveData` — отключаются видео и предзагрузка страниц

## Image Optimization

### Форматы
- **WebP** — основной формат всех артов и страниц комикса (поддержка во всех целевых браузерах)
- **Fallback**: JPEG для старых браузеров через `<picture>` → `<source type="image/webp">` + `<img src=".jpg">`
- PNG только для изображений с прозрачностью, где критичен альфа-канал (логотипы-руны)
- AVIF — опционально в будущем, без блокировки (проверка поддержки через decode-тест)

### Responsive sizes
```html
<img src="art_800w.jpg" srcset="art_400w.jpg 400w, art_800w.jpg 800w, art_1200w.jpg 1200w"
     sizes="(min-width: 1024px) 50vw, (min-width: 768px) 33vw, 100vw" />
```
- Храним 3 производные ширины: 400w, 800w, 1200w (максимум 1600w для страниц читалки)
- Брейкпоинтные value: hero — 100vw, карточки галереи — по сетке
- Имя файла содержит ширину (`_400w`), чтобы избежать дублирования

### Уровни компрессии
- Арты галереи: WebP, качество 82 — баланс «арт-сайз/детали»
- Страницы комикса: WebP, качество 75 — приоритет скорости листания
- Обложки/превью в карточках: WebP, качество 70
- PNG с альфа-каналом (лого-руны) — без потерь, пережатие q92

### Placeholder-стратегия
- **LQIP**: размытый placeholder (WebP 20-40px, quality 40) через `blur-up` при скролле
- Или **dominant color**: `background-color: var(--bg-raised)` + низкоприоритетная загрузка
- Для страниц комикса — shimmer-skeleton (см. Читалка), для артов — цветовая плашка из `--accent-ember-10`

## Error States

### 404
- Кастомная страница в стиле вселенной: лавовый фон-градиент, текст «Страница поглощена тьмой» (Cormorant, `--fs-display`)
- Кнопки: «Вернуться домой», «Читать комикс» — ссылки на реальные маршруты
- Мета: `<meta name="robots" content="noindex">` на отдельной странице 404

### Ошибки загрузки медиа
- Изображение: `onerror` → placeholder (см. Читалка) + `error`-лог в консоль
- Видео hero: `preload="none"` + poster; при `error` — статичная подложка-арт вместо черного экрана
- Повторяет загрузку несколько раз (максимум 3 попытки), затем показывает fallback-арт

### Error Boundary
- React Error Boundary вокруг читалки и галереи (Region-уровневые)
- На падение — fallback-экран: «Что-то пошло не так» + кнопка «Перезагрузить читалку» (мягкий reload состояния, без полной перезагрузки страницы)
- Ошибки не роняют всю страницу — только секцию; остальные продолжают работать
- Наблюдение: ошибки репортятся в console/аналитику с тегом версии чанка

### Offline режим
- Service Worker (Workbox): прекэш критических ресурсов (CSS, шрифты, иконки, первая глава — 10 страниц)
- Стратегия: stale-while-revalidate для артов, cache-first для страниц комикса
- Офлайн-баннер: «Вы офлайн — показываю сохранённое» с индикатором в navbar
- Возврат соединения: повторная регистрация SW, синк читательской позиции через localStorage

## Z-Index Hierarchy
| Уровень | Элемент | Значение | Контекст |
|---|---|---|---|
| 1 | Фон страницы | `0` | `--bg-void` |
| 2 | Контент | `10` | секции, карточки |
| 3 | Navbar | `100` | sticky, поверх контента |
| 4 | Мобильное меню | `200` | полноэкранное выезжающее меню |
| 5 | Прогресс-бар читалки | `300` | sticky-панель прогресса |
| 6 | Тултипы / hover-подсказки | `400` | поверх navbar |
| 7 | Lightbox / полноэкранный просмотр арта | `500` | затемнение + контент |
| 8 | Модалки | `600` | диалоги подтверждения |
| 9 | Читалка (полноэкранная) | `700` | приоритетнее модалок внутри |
| 10 | Toast / уведомления | `800` | поверх всего |

- Значения фиксированы в CSS-переменных: `--z-base: 0; --z-content: 10; --z-navbar: 100; --z-menu: 200; --z-reader-bar: 300; --z-tooltip: 400; --z-lightbox: 500; --z-modal: 600; --z-reader: 700; --z-toast: 800;`
- Внутри читалки свои уровни: панель глав = `--z-reader + 10`, превью-навигация = `--z-reader + 20`
- `backdrop-filter` оверлеи используют `position: fixed` и не выходят за свои контексты
