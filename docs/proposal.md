# Webtoon Reader — Цифровой артбук и комикс

> Первый документ методологии OpenSpec. Этот документ является источником истины для всего проекта.

## Цель и миссия
Создание иммерсивной платформы для демонстрации цифрового артбука и комикса в стиле славянского фэнтези для взрослой аудитории. Проект направлен на предоставление уникального визуального опыта с богатыми анимациями и переходами.

## Целевая аудитория
- Взрослая аудитория (18+)
- Любители славянской мифологии и фэнтези
- Ценители качественного визуального контента
- Читатели вебтунов и цифровых комиксов

## Ключевые функции
1. Hero секция с видео на заднем фоне
2. Блок "О проекте" с изображением и описанием
3. Галерея концептов с фильтрацией по персонажам (split-screen 20/80)
4. Раздел команды проекта
5. Блок поддержки (социальные сети, Boosty, Patreon)
6. Полноэкранная читалка комикса с навигацией (по главам, вперёд-назад)

## Текущее состояние проекта
- Уже инициализирован Vite + React проект
- Установлены: GSAP, Lenis, lightningcss
- Есть папки: `docs/`, `src/components/`, `src/animations/`, `sources/`
- В `sources/` лежит `bg_video.mp4` и папка `ART` с примерами артов

## Технологический стек и обоснование

### Основной стек
- **Фреймворк**: React + Vite
- **Анимации**: GSAP + Framer Motion
- **Скролл**: Lenis
- **Стили**: Чистый CSS + CSS Variables + lightningcss
- **Роутинг**: React Router DOM

### Почему GSAP и Lenis
- GSAP и Lenis **уже установлены** — не требуется дополнительных зависимостей
- GSAP — индустриальный стандарт для high-performance анимаций: работа с timeline, scrollTrigger и интерполяцией, оптимизированная через внутренний ticker
- Lenis — сглаженный инерционный скролл, который синхронизируется со скролл-анимациями GSAP, создавая эффект премиального скроллинга (вау-эффект)

### Дополнительные библиотеки и зачем они нужны
- **Framer Motion** — декларативные анимации для React-компонентов (появление секций, переходы страниц читалки), удобство работы с состояниями
- **React Router DOM** — навигация между страницами сайта (главная, читалка комикса) без перезагрузки
- **lightningcss** — уже установлен, быстрый минификатор/трансформатор CSS на Rust, ускоряет сборку

### Как стек решает требования к производительности
- GSAP преобразует анимации в GPU-ускоренные transform/opacity, избегая layout thrashing
- Lenis использует requestAnimationFrame и не блокирует главный поток
- Framer Motion выносит анимации из React render-цикла (worklet-free, transform-only подход)
- lightningcss на порядок быстрее PostCSS при сборке
- Итого: плавные анимации на слабых мобильных устройствах без просадок FPS

## Критерии успеха проекта
1. **Скорость анимаций**: не менее 60 FPS при анимациях и скролле на мобильных устройствах среднего класса
2. **Производительность загрузки**: Lighthouse Performance ≥ 90 на десктопе и ≥ 80 на мобильных
3. **Адаптивность**: сайт корректен на всех разрешениях от 320px до 4K (mobile-first)
4. **Функциональность читалки**: навигация по главам и переключение страниц вперёд-назад без перезагрузки
5. **Контент**: все арты из `sources/ART` отображаются, фильтр по персонажам в галерее работает
6. **Деплой**: статический сайт собирается без ошибок и работает локально на хостинге

## Ограничения и требования
- Статический сайт (без бэкенда)
- Локальное хранение всех изображений на хостинге
- Полная адаптивность (mobile-first подход)
- Оптимизация производительности для плавных анимаций
- Приватность данных (никакой телеметрии)
